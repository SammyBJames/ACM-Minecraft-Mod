# Code of Conduct

## Our pledge

This project is a place for students to learn how open source works. Contributing should be a welcoming, harassment-free experience for everyone.

## Expected behavior

- Be kind and patient.
- Accept feedback gracefully and assume it is offered in good faith.
- Ask questions freely, and answer them without talking down to anyone.
- Give credit to others for their work and ideas.

## Unacceptable behavior

- Harassment, insults, or demeaning comments of any kind.
- Sexualized language or imagery.
- Publishing someone else's private information without their permission.
- Deliberately disrupting issues, pull requests, or discussions.
- Any other conduct that would be inappropriate in a classroom or
  professional setting.

## Scope

This Code of Conduct applies in all project spaces: issues, pull requests,
discussions, and code review.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, issues, and pull
requests that do not follow this Code of Conduct, and may temporarily or
permanently block a contributor from the project for behavior they consider
inappropriate, threatening, or harmful.
