# Contributors

Everyone who has contributed to this project has a file in this directory.
Adding yours is the required first contribution: it walks you through the
full issue → fork → branch → pull request cycle without needing to make changes to the
mod.

Follow the step-by-step guide in
[CONTRIBUTING.md](../CONTRIBUTING.md#your-first-contribution-add-your-name).

## Rules

- Create **one new file** named `<your-github-username>.md`, for example
  `octocat.md`. Start from a copy of [`_TEMPLATE.md`](_TEMPLATE.md).
- Do not edit `_TEMPLATE.md`, this README, or anyone else's file.
- Fill out the entire template
- Ensure you are following the [Code of Conduct](../CODE_OF_CONDUCT.md).
